# Cursor AI Monitor

> 实时显示 Cursor AI Agent 正在修改的文件，像 Cline 一样实时查看代码修改过程

[![Version](https://img.shields.io/badge/version-0.1.1-blue.svg)](https://github.com/)
[![VS Code](https://img.shields.io/badge/VS%20Code-1.105.0+-blue.svg)](https://code.visualstudio.com/)

## ✨ 功能特性

- 🔄 **实时 Diff 视图** - AI 修改代码时自动打开对比视图，实时显示修改内容
- 📊 **状态栏监控** - 底部状态栏显示当前 AI 正在编辑的文件和修改进度
- 📈 **修改统计** - 显示修改的文件大小和耗时
- 🗂️ **文件创建检测** - 检测 AI 创建的新文件
- 💾 **保存检测** - 检测 AI 保存文件的动作
- 🔍 **纯监控模式** - 只读取不写入，完全不干预 Cursor 的正常工作

## 🎯 效果预览

当 Cursor Agent 修改文件时：

**状态栏显示：**

`🔄 AI 编辑: src/main.c 2.3KB`

**自动打开 Diff 视图：**

`AI 正在编辑: main.c` 对比窗口，绿色表示新增，红色表示删除

## 🚀 使用方法

### 安装即用

扩展安装后自动激活，无需任何配置。

### 查看 AI 操作

当 Cursor Agent 修改文件时，你会看到：

1. **底部状态栏** - 显示当前正在编辑的文件名和修改大小
2. **Diff 视图** - 自动打开对比窗口，绿色表示新增，红色表示删除

### 命令面板

按 `Ctrl+Shift+P` 打开命令面板，可使用以下命令：

| 命令 | 功能 |
|------|------|
| `AI Monitor: 重置状态` | 清除所有监控记录，重置状态栏 |
| `AI Monitor: 查看当前状态` | 显示当前 AI 正在操作的文件 |

## 📋 监控状态说明

| 状态图标 | 含义 |
|----------|------|
| 🔄 | AI 正在编辑文件 |
| 📄 | AI 正在创建新文件 |
| ✓ | AI 编辑完成 |
| 💾 | AI 保存了文件 |
| 👁️ | 空闲，等待 AI 操作 |

## 🔧 工作原理

- 监听 VS Code 的文件变化事件
- 检测批量修改（AI 操作的典型特征）
- 实时生成并更新 Diff 对比视图
- **完全只读，不修改任何文件**

## ❓ 常见问题

### Q: 会影响 Cursor 的正常工作吗？
A: 不会。扩展只读取文件内容用于对比，不写入任何文件。

### Q: 为什么有时候检测不到？
A: Cursor Agent 的写入方式可能不同。扩展通过检测批量修改来识别 AI 操作，如果修改量很小可能不会被识别为 AI 操作。

### Q: 如何确认扩展是否激活？
A: 查看底部状态栏是否有 "👁️ 监控 AI 操作..." 字样。
